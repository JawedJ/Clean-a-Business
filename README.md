# Clean a Business
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0-rc.1.

## About
Simulator-style Roblox game. Players take cleaning **jobs** at shared businesses, wash/scrub
their surfaces, stains, and spills with tools (pressure washer, broom, mop), and earn **Cash** +
**XP**. Each
player also gets a personal **plot** with a **purchase progression**: step-on **Buttons** bought
with Cash reveal **Spawnables** that passively generate **Gems**. The server is authoritative;
clients send validated intent and render replicated data. The unlock catalog (tools, businesses,
plot buttons) is data-driven and grows additively.

The full technical spec — architecture, systems, and design principles — lives in
[`docs/CleanABusiness.md`](docs/CleanABusiness.md).

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "Clean a Business.rbxlx"
```

Next, open `Clean a Business.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
